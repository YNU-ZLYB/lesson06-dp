本项目用 Python 实现并对比了两种经典算法策略：**贪心算法**与**动态规划**，包含硬币找零和 0/1 背包两个问题，并附有输入校验、测试用例、结果验证与性能分析。

## 一、核心结论（课堂检查点）

| 问题 | 贪心算法 | 动态规划 |
|---|---|---|
| 面额 [1, 5, 11] 凑 15 元 | 5 枚（11+1+1+1+1） | **3 枚（5+5+5）** |
| 登山背包（限重 1000 克） | — | 最优重要度 **315**：睡袋 + 食物 + 水具 |

结论：贪心每步只取当前最大面额，不一定得到全局最优；动态规划通过填 dp 表保证最优解。

## 四、模块组成（run_all.py 依次执行）

1. **输入校验**（coin_validation）——拦截负数、小数、空面额等非法输入，含可解性预判
2. **测试用例**（coin_test_cases）——8 组正常用例 + 6 组异常用例，全部断言通过
3. **结果验证**（coin_verify）——校验组合来源、求和、枚数一致性，小金额用暴力枚举交叉验证
4. **性能分析**（coin_performance）——对比不同金额下贪心与 DP 的耗时与峰值内存
5. **复杂度可视化**（coin_visualize）——ASCII 柱状图直观展示增长趋势

## 五、复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 |
|---|---|---|
| 贪心 | O(枚数)，基本与金额无关 | O(枚数) |
| 动态规划（硬币） | O(n × k)，n=金额，k=面额种数 | O(n) |
| 0/1 背包 | O(n × W)，n=物品数，W=容量 | O(n × W) |

实测：贪心耗时/内存基本平坦，DP 随金额线性增长——这是 DP 用空间换最优性的代价。
